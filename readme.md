<h1 align="center">VOID CLOUD 🦇</h1>

###

Este é um servidor simples escrito em Python que permite transferências de arquivos via web. Ele oferece uma interface básica para fazer upload e download de arquivos diretamente pelo navegador.

Funcionalidades
Upload de arquivos para o servidor.
Download de arquivos armazenados.
Interface web leve e fácil de usar.
Os arquivos enviados são automaticamente removidos do servidor após 1 minuto de inatividade (quando não há acessos ou uploads recentes).
Isso garante privacidade e evita acúmulo de dados, mas certifique-se de baixar os arquivos necessários antes que expirem.
